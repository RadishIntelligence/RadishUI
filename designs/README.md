# 原生设计源

[`radish-ui-workbench-v1.pen`](radish-ui-workbench-v1.pen) 为 Pen App / Pencil MCP 创建的原创 Workbench 候选，含 12 个主组合、4 个辅助板与 6 个可复用部件。只通过 Pencil / Pen 读写 `.pen`，不使用文本、脚本或其他解析器。

评审、来源与未覆盖面见 [Workbench v1](../docs/design/patterns/workbench-v1.md)。[manifest](workbench-v1.manifest.json)记录 frame ID 与导出，[variables](workbench-v1.variables.json)为原生 API 读取的候选参数，[contrast](workbench-v1.contrast.json)为指定实色对照计算。它们不替代运行时 token 来源。

所有内容为合成示例。外部参考原图没有进入设计源。这里的候选尚未获得视觉批准，不代表 React、Flutter 或产品已接入。
