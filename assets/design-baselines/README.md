# 设计基准与候选

`candidates/2026-11-04-modern/` 保存当前现代圆角探索的 14 张 Pen 原生导出，三页桌面明暗已同步独立底板与连续导航侧栏。来源、frame ID 和尺寸见 [modern manifest](../../designs/modern-rounded-v1.manifest.json)，评审见[现代圆角探索](../../docs/design/patterns/modern-rounded-v1.md)。

`candidates/2026-11-04/` 保留 Workbench v1 的 18 张原生导出，包含移动胶囊导航与选择器修订，对应[原 manifest](../../designs/workbench-v1.manifest.json)与[旧候选](../../docs/design/patterns/workbench-v1.md)。`candidates/2026-11-03/` 的 16 张首稿作为历史快照保留；本轮不覆盖这两个目录。

候选目录明确表示尚未获视觉批准，不能作为强制回归基准。获批后另登记版本、视口、主题、环境与批准记录，再确定正式基准路径。运行时临时截图仍放在忽略的 `output/`。

仅保存自有合成内容，不存第三方参考截图、私人材料或未经确认的品牌素材；图片不放入展示站 `public/`。本轮未将字体或图标文件作为独立素材分发。
