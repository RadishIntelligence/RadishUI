- **G6 焦点归还**：Radix 在关闭前会把焦点放到 viewport，之前没有共享层归还逻辑，关闭后焦点留在空的不可见区域；App 又用 `key={notice.id}` 重挂载 Toast，实例内记录会丢失。现在打开时记录打开控件（优先 `document.activeElement`，鼠标点击场景由模块级 `pointerdown` 记录兜底，覆盖 macOS Chrome 点击按钮不聚焦），首次以 F8 / Tab 进入提示时记录进入前位置；关闭且焦点仍在提示内或已丢失时，优先回到打开控件，其次回到进入前位置，两者都不可用（如保存后按钮变为 disabled）时把焦点移出空 viewport。自动消失且用户已在别处操作时不抢焦点；`prefers-reduced-motion` 下同样成立。

- **G8 移动选中态**：移动资源按钮补 `aria-pressed`，与桌面表格按钮同语义；`li` 不加 `aria-selected` / `aria-current`，避免与按钮语义混用。视觉高亮、详情抽屉和桌面行为不变。
