### TagInput 跨浏览器补验（2026-11-09）

- 起点为 `dev` / `1e176ea`，工作区和暂存区干净。环境为 macOS 27.0.1（26A434）、Node 24.16.0、Safari 27.0.1（safaridriver 22625.1.29.11.28）、Firefox 159.0.1。两款浏览器的 UA、启动命令、结果 JSON 与截图保存在忽略目录 `output/playwright/2026-11-09-taginput-cross-browser/`。
- 在仓库根运行 `npm run dev`（127.0.0.1:4510）。在证据目录运行 `node server.mjs`（127.0.0.1:4511）和 `node audit.mjs firefox`、`node audit.mjs safari`。Safari 使用 `/usr/bin/safaridriver -p 4452`，BiDi 8090 用于导航和 DOM 取证，W3C HTTP 用于原生键盘、指针和截图，视口由同源 iframe 固定。Firefox 用独立临时 profile、9223 上的 BiDi 和实际 CSS 视口。先跑无头，最终采用前台实例，沿用默认内容沙盒。
- 两款浏览器分别通过布局 **12 / 12**、功能流程 **4 / 4**（44 项断言）。布局为资源新建和组件页字段组 × 1440×900 / 16px、390×844 / 16px、320×568 / 32px × 明暗。应用界面设为 English，组件示例保留现有中文标签。两处 TagInput 均无横向溢出，320px 的 40 字符标签正常换行，390px 组件示例有足够宽度时保持单行。
- 原生指针与键盘验证初始焦点、Escape 回入口、Enter / 添加按钮、逐项删除、空输入 Backspace 与操作后回输入框。混合逗号和空格、大小写去重、8 项 / 40 字符边界、超限保留、保存详情和刷新后搜索、取消与重开、示例错误和禁用均通过。输入准备与 composition / 229 守卫使用合成事件。Firefox 前台以 Tab、Safari 以 Option+Tab 到达删除按钮，截图可见焦点环。Safari 普通 Tab 受当前网页键盘导航偏好限制。
