# 现代圆角：代表页探索

2026-11-04。状态：**所有者暂定本版作为首轮 Web 实施起点，运行效果继续评审**。承接所有者对本地参考 `ref-01` 至 `ref-29` 的明确偏好：美式、现代、微圆角、胶囊感。这里维护原生设计与转译依据；token、组件、真实页面分别归 F-01、C-02、E-02，尚未冻结正式发行 token 或公共 API。

已保存的 [Workbench v1](workbench-v1.md)以 `c6eba89` 提交保留；本轮在同一原生设计文件中新增 `MR /` 画板组，旧画板和导出不覆盖。首轮任务进度仍只在 [F-02](../../features/visual-baseline-proposal.md)维护。

## 视觉方向

- **表面**：浅灰中性背景承托白色内容面，深色使用中性炭黑与灰阶层次；不再以暖绿色铺满深色背景。灰玉保留在文字品牌，墨蓝用于操作与选中。
- **形态**：内容面约 16px 圆角，应用主内容面 20px；选择器约 10px，主题选项与局部提示约 12px；按钮、搜索、分段选择与状态使用胶囊。目录在一块整体区域内连续组织，不再逐项使用胶囊；长表单与连续行保留平直的阅读边缘。
- **触感**：细边界配合填充区分控件；选中分段和移动胶囊只加轻微阴影，菜单与反馈适度抬升。侧栏通过整体底板承托连续导航，行本身不加阴影或边框；没有为所有内容加卡片或整屏高光。
- **交互辨识**：侧栏是独立内容面，普通导航、收藏与帮助沿同一底板连续组织，当前项用柔和填充和图文强调。账号入口保留边界与轻阴影，工作区切换用柔底和细边界；目录共享紧凑底板，以侧边标记和文字强调当前章节，折叠、菜单和页码保持明确入口。资源表保留连续内容与行末打开按钮；右侧属性、摘要与正文仍平铺。交互不依赖 hover 才被发现。
- **排版**：桌面主标题 28px、阅读标题 32px、界面文字 13–14px、正文 15–16px；移动标题 26px，主要选择 / 保存区域至少 44px。辅助信息最小 11px，真实实现仍须验证缩放与大字号。
- **页面**：R1 用连续资源表与当前详情判断扫描效率；R2 用主题预览、行式字段、分段密度与清楚的保存动作判断控件触感；R3 用正文、轻目录与元信息判断长时间阅读。没有照搬参考里的 KPI、图表或产品领域。
- **移动**：延续已明确要求的内收底部胶囊，图标在上、文字在下；同一套表面与控件重新编排为单列。设计预留左右 16px、底部 20px；导航高 72px、外圆角 36px，内部四周统一 6px，高亮高 60px、圆角 30px，宽度随三等分槽位填充，消除原先两端与上下内边距不一致的问题。运行版另使用系统安全区变量，真实设备验证归 E-02.5。

这些是本轮设计参数；获准的 Web 实施通过 [F-01](../../features/token-foundation.md)映射到 `packages/tokens/src/tokens.json` 的语义角色，不将旧 family-ui 或 Pen 变量直接作为生成入口。原生导出与真实 Web 验收分别判断。

具体设计规则统一见[设计条例与约束](../design-rules.md)。所有者已选择[独立底板、连续列表、当前项高亮的侧栏方案](../design-rules.md#sidebar-navigation)，已同步三代表页的桌面明暗候选；账号与工作区切换仍为独立控件。此选择不代表整套视觉获批。

### 首轮细节反馈

- 桌面导航项由 44px 收紧为 36px，项间距由 6px 改为 4px；侧栏分组和收藏区同步收紧。触控底栏保持原有高度。
- 账号头像由 32px 调整为 36px，两行文字通过行高和 2px 间距形成约 35px 的文字块，整体居中对齐。
- 页面主标题和工作区名称下的装饰性描述移除；字段帮助、资源摘要、账号角色与文档正文仍承担各自信息职责。
- R1 分页补齐总条数、每页条数、前后页、当前页和指定页码输入 / 跳转。主稿真实保留 8 项，单页时前后页不可用；控件板另用 240 项、每页 10 项、第 6 页的合成状态展示邻近页、首末页与省略号，不把主稿伪装成多页数据。
- 分页仍是静态构图。实现时须将页码限制为 1 至总页数的整数，页大小变化后重置至第一页，并验证焦点、禁用、越界反馈与窄屏布局；当前不承诺分页 API 或服务端能力。
- 后续反馈要求账号区浮起，并让可交互区域区别于静态展示。六张桌面稿的账号区统一为 56px 高的独立入口，保留 36px 头像与居中文字；同类入口补齐底色 / 边界，主导航当前项采用柔底和轮廓。移动资源保留文字状态，使用独立打开按钮替代重复状态图标，并保留 44px 触控区；移动文档编辑入口同步为 44px。默认、选中与焦点不互相代替。
- 容器与控件留白继续收紧：桌面外部留边 8px，主内容左右 16px、底部 12px；表格行左右 12px、详情左右 12px、双面板间隔 12px；分段项与选择器左右 8px，搜索和次按钮左右 10px，主按钮左右 12px。普通内边距优先 8–16px，标题上方等真实层级留白单独判断；字号、行高、资源行高和移动触控高度不变。
- 分页区固定高 52px、上下内边距 8px，剩余高度由列表数据区域承接，避免将表格拉伸误变为分页的大内边距。固定宽度的密度分段改为等分槽位，缩小内边距后仍保持对称，不把多余宽度堆在一侧。
- 侧栏改为一块独立底板：外侧留边 8px，面板 208×884px、圆角 16px，内部左右 12px。页面入口高 36px、间隔 2px；收藏与帮助使用连续行，去掉逐项填充、边框与阴影。当前项保留 8px 圆角柔底，图文使用操作色，不再以轮廓模拟焦点。工作区切换用柔底，账号保留细边界、轻阴影和 36px 头像；三页各自的当前项与明暗同步。移动底栏及控件状态板沿用既有稿。
- R3 桌面目录改为 220×133px 的整体区域，内边距 12px；连续章节行高 28px、无行间距，去掉单项胶囊和填充，当前章节使用 2px 侧边标记与文字强调。三章节在正文中同级，因此目录也同级；后续子标题按真实正文层级缩进，规则见[目录层级](../design-rules.md#document-outline)。移除区域下方重复分隔线，辅助区间距收为 20px；只读属性继续平铺，未改动正文或移动稿。
- R3 桌面正文使用 `fill_container` 自适应占满剩余空间，辅助栏保持 220px、栏间隔 24px。在 1176px 可用宽度内，正文实际宽 932px，内容两侧只保留页面原有的 16px 基础内边距；此前固定 680px 正文并居中、两侧各留 126px 的方案已取消。字体与内容保留，文本按新的可用宽度自然换行，明暗同步。移动稿继续单列；这些是画稿参数，真实中间宽度检查归 E-02。

## 运行版对应与差异

`f1c2eef` 已保存本仓首轮 Web 实施，直接使用 [F-01](../../features/token-foundation.md)的语义 token 和 [C-02](../../features/react-workbench-components.md)共享组件。运行版已登记为 [F-02.4 第二版](../../features/visual-baseline-proposal.md#第二版运行基线登记2026-11-08)，行为与验收归 [E-02](../../features/workbench-preview.md)。原生画稿继续作为构图依据。

| 项目 | 原生画稿 | 当前运行版 |
| --- | --- | --- |
| 字体与图标 | Pen 内 Noto Sans SC / Lucide 绘制 | Inter Variable / JetBrains Mono Variable，CJK 回退系统字体；使用 rem 和按需 Lucide React |
| 移动资源 | 前六项与“查看全部 8 项”静态入口 | 同源资源列表和本地分页；默认可滚动浏览全部 12 项 |
| 密度选择 | 三等分分段候选 | 横向 RadioGroup，紧凑 / 标准 / 宽松对应主要控件的最小高度（30 / 34 / 38px），标准为默认；标准与紧凑收敛工作区留白，宽松回到基础间距 |
| 移动导航 | 三入口胶囊 | 概览、资源、文档、偏好四项；设计系统页也可从账号菜单进入 |

2026-11-05 所有者大部分认可整体运行效果，要求收敛桌面按钮、输入框、选择器的视觉体量。运行站默认采用已有 36px compact 密度，设置选择器列宽收至 192px，已保存偏好保持有效；本轮未修改原生稿。

随后所有者以桌面侧窗对照明确要求提高整页信息密度。运行版进一步区分可用宽度与输入方式：鼠标窄窗不使用触屏控件尺寸；compact 页标题为 22px、页头约 48px，字段行上下留白 8px、主题预览 36px，资源行约 52px。窄桌面表单宽度达到 28rem 时并排呈现说明和控件，文字放大后可回单列；底部导航按后续反馈统一图标在上、文字在下，窄桌面紧凑高度约 56px。触屏窄窗沿用原 72px 纵向胶囊与安全区，主要控件至少 44px。组件用法间距同步收紧，阅读正文不随工作区密度缩放；该轮运行版仍待复评。

同日所有者进一步要求底栏按内容确定整体宽度。运行版胶囊改为内容自适应并居中，各入口由图标、标签和水平留白决定，不再把剩余屏宽分配到三等分槽位；视口不足时收缩并允许标签折行。触屏入口仍至少 44px，既有底部安全区与高度不变；原生稿中的等分宽度属于此前候选记录。该内容自适应方案已于 2026-11-05 被约 252×52px 胶囊底栏（20px 图标 / 10px 文字、约 76px 活动胶囊、底板 / 活动各 1px 边框、3px 胶囊间距、8px 内容间距）取代，见下文 B1。
