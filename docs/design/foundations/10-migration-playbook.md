# 10 版本、产品采用与回滚

文档集中、视觉批准、token 升级、组件采用和发行分别验收。把资料移动到 RadishUI，不代表产品已经完成接入。

变更 token 名称、语义、默认视觉或公共 API 前说明消费位置、兼容影响与迁移。旧 family-ui 与当前工程存在同名不同义项；保留固定来源，明确逐项映射，不能同时加载或以链接替代构建需要的本地文件。

产品保留薄适配说明，只记录：

- 采用的 RadishUI 固定版本 / 提交、Profile 与主题映射；
- 真实使用的组件、页面及平台，明确未采用部分；
- 必要产品例外、原因、范围和退出条件；
- 产品设计源、业务合同、实现映射与验收链接；
- 升级验证、回滚版本与负责人。

通用原则和参考索引仅链接到 RadishUI，不再复制维护；产品历史记录保留原文，通过旧路径短入口追溯。没有发布的新链接应明确本地候选状态，来源分支须待目标提交可访问后再推送 / 合并。

迁移顺序：确认范围 → 目标到位并校验 → 更新旧入口 → 移除当前树重复副本。私有原图先逐字节校验并写入完整映射，再移除源副本；Git 历史不重写，普通修复 / revert 可恢复。私有资料不因迁移获得新的对外许可。

采用方升级分别完成真实验证。有限试点候选仍为 Nexus 阅读 / 设置局部与 Mind 资源列表局部；本次没有启动产品或修改产品代码。
