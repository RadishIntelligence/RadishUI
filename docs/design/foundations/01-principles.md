# 01 设计原则

家族气质是温润、克制、清晰；先让界面适合长时间工作，再以少量品牌色体现识别。东方温度不等于整屏米黄、传统纹样或衬线正文。

具体设计条目、默认原则与特殊设计例外统一见[设计条例与约束](../design-rules.md)；参考提炼建议和所有者已确认内容分别标注。

1. 页面只有一个明确主任务。列表负责扫描与选择，详情解释当前对象；辅助区不能抢走主内容。
2. 内容连续组织。相关事实使用行、段落与适量分隔；独立对象才需要卡片，避免卡片套卡片和等权信息块。
3. 阅读和操作优先。字号、边界、单位与状态先可辨，再调整气质与密度。
4. 颜色表达角色。品牌识别、常规操作、选择与业务状态相互独立；文字或图标提供第二通道。
5. 装饰有用途和边界。工作面不默认放纹理、展示外框、营销 Hero、KPI 卡带或第二条导航。
6. 共享建立在语义上。设计基础与组件不接管权限、HTTP、路由、领域状态或产品布局合同。
7. 从起点考虑明暗、窄屏、长内容、焦点、触控和减少动态效果；响应式同时验证可用宽度和输入方式。

## 响应式与输入方式

响应式不是单一宽度截图。先确定内容在可用宽度下如何重排，再设置断点；触屏 / 鼠标只决定命中区、hover 和精度相关增强，不用于隐藏与输入方式无关的紧凑布局。所有可点击目标在触屏上保持至少 44×44 CSS px，视觉可以更小但命中区不能缩水。

紧凑尺寸、间距和字号如果被写入 `@media (pointer: ...)`，必须说明它是否真的只服务于该输入方式；底栏高度、内容底部避让等布局规则默认同时适用于 fine / coarse。验证时成对检查两种输入方式，并确认 `matchMedia('(pointer: coarse)')` 的真实值，不能只靠视口宽度或截图推断。

展示站外壳与页面 chrome 的视觉尺度见[DR-17](../design-rules.md#dr-17)：桌面 32px、移动 36px，触屏命中保持 44px；新增页头、工具栏、分页等 chrome 先沿用这套尺度，避免各区域大小漂移。

详见[设计条例 DR-16](../design-rules.md#dr-16)：响应式与输入方式适配。使用[参考索引](../references/README.md)时，记录学习的空间关系、适用原因和排除项，再围绕自己的内容重组。不复制外部品牌、图标、图片、文案或独特页面组合，也不用换色截图作为原创交付。

明确避免：米色雾感、厚重国潮、荧光状态、大面积渐变光斑、塑料高光、无职责的巨大容器、把未实现能力画成已可执行路径。Mind 的设计退回经验说明，相同 token 无法弥补主任务与内容关系不清。
