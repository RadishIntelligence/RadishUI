# 04 空间、形态与层级

以 4px 为基础网格，但尺度名称必须以所用版本的来源为准。当前工程 `space-6=24px`、`space-8=32px`，旧 family-ui 分别为 32px / 64px；同名不同义不能混用，详见[历史参考](legacy-v26.7.3/README.md)。

Workbench v1 候选使用桌面 224px 主导航、32 / 40px 内容边距、40px 控件；窄屏 20px 边距、至少 44px 触控区。它们是页面构图和候选参数，不全部升格为共享 token。中间宽度的收缩、侧栏退出及滚动需要在真实实现中验证。

控件圆角约 6–8px，浮层约 8–12px。当前工程 `radius-panel=16px` 仍保留，候选尚未改写运行时。分隔线用于关系；可交互边界与装饰分隔分别处理，不能让浅线承担唯一的控件辨识。

2026-11-04 所有者明确偏好现代、微圆角与胶囊感；[现代圆角探索](../patterns/modern-rounded-v1.md)另行验证选择器 10px、局部提示 / 主题选项 12px、内容面 16px、主内容面 20px，以及按钮 / 搜索 / 分段 / 状态的胶囊形态。上述 6–8px 是此前候选范围，不作为阻止本轮探索的硬门禁；两个方向待评审后再决定共享尺度。

默认紧凑留白与候选尺度统一见[DR-03](../design-rules.md#dr-03)。实际布局中，分页等操作区与未占满的数据区分别处理，避免以撑大组件内边距填满视口；父子容器也不重复叠加相同职责的 padding。

优先通过排版、间距与表面区分层级。静态内容不默认加阴影，浮层适度抬升；现代圆角候选允许选中分段、移动胶囊和账号入口有微弱阴影以表达操作层次，不延伸为所有面板的默认效果。侧栏以整体底板承托连续导航，行本身不逐项抬升。交互与静态展示的默认边界、共享底板与特殊设计例外按[DR-02](../design-rules.md#dr-02)处理。禁止用双层白框和卡片嵌套制造纵深。焦点与 hover、选中分别表达，焦点不被父容器裁切。

实现按普通内容 → sticky → 菜单 → 遮罩 / Dialog → 全局反馈定义层级职责。具体 z-index 与浮层容器在实现合同中明确，不把旧数值表直接复制成新平台约束。
