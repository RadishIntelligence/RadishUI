主要归属：[展示、页面范例与产品采用](../planning/topics.md#examples)。协同 F-01、C-01、G-02；阶段为 P0 工程基线。架构依据为[展示站职责](../architecture/overview.md)。

本页保留 P0 的历史验收身份。2026-11-04 本地展示入口已进入 [E-02 三代表页](workbench-preview.md)实施，以下 P0 界面不再描述当前工作区；线上仍以实际 master 部署为准。

## 场景与边界

`apps/docs` 作为独立 React / Vite 静态展示站，用真实 token 和 Button 检查主题、组件层级、状态与窄屏布局。包含概览、语义色块、按钮和平台状态说明；不等于已具备完整文档搜索、工作台列表 / 详情、设置页或跨产品采用看板。

主题初值读取浏览器偏好，用户可切换亮暗；交互按钮使用本地定时示例并以状态文本反馈，结束后恢复加载状态。示例不连接业务后端，不把演示成功写成真实保存成功。产品采用和正式代表页须按[设计系统契约](../development/design-system.md)另行确认。

## 失败、恢复与验证

共享组件或 token 不一致时修复其来源，不在展示站复制一份修补实现；构建失败应保留真实错误。交互状态变化核对加载、禁用、状态反馈与键盘焦点。视觉检查覆盖桌面 / 窄屏、明暗与长内容；临时截图在 `output/`，记录源码、环境和未覆盖范围。
