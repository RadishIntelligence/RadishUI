## 目标与输入输出

以[现代圆角候选](../design/patterns/modern-rounded-v1.md)作为实现起点，展示站直接消费共享 token、控件与图标，形成资源库、设置和文档三页。范例不接产品接口，没有真实登录、权限判断、云端保存或协作编辑。

应用默认进入概览 `#/overview`，设计系统入口还包括 `#/catalog`、`#/components`、`#/foundations` 和 `#/platforms`；组件目录与 `#/components/<id>` 独立页归 [E-03](component-site-1.md)，本文件继续维护 Workbench 三页。演示使用 `#/resources`、`#/settings`、`#/document`，资源文档为 `#/document/<id>`，章节地址继续附加 `/<section-id>`。应用导航由展示站维护。

## 本地数据、失败与恢复

- 偏好、资源、文档各使用一个 `radishui.*.v1` localStorage 键。资源和文档使用 v1 信封，偏好使用 v2，读取旧偏好时将旧 `compact` 迁移为 `standard`，其余有效旧密度迁移为 `spacious`。读取时验证结构、枚举、长度、日期与资源 ID 唯一性。实际写入成功后更新已保存状态。
- 缺少记录时使用合成初值，空数组是有效的空资源库。JSON 损坏、未知格式或浏览器存储不可用会显示真实失败，不用默认成功掩盖；资源页的页面操作菜单可恢复演示资源，文档库另有重新初始化入口，两者分别确认范围，不影响另外两类数据。
- 写入失败保留草稿；未保存离开有确认，刷新 / 关闭窗口使用浏览器离开提示。收到其他标签页的数据变更后提示重新载入并阻止覆盖，不承诺自动冲突合并。
- 复制链接只在 Clipboard API 成功后显示已复制；不可用时保留链接并提示手动复制。页面不执行站外消息发送。
- 文本经 React 正常转义，不解析任意 HTML；新建 / 编辑有长度和必填约束。示例账号、时间与资源均为合成内容，不引入真实个人数据。
- 资源上限 500 项，已保存文档修改上限 500 份；名称 / 标题最长 120 字符、资源摘要最长 1000 字符、正文最长 50000 字符。删除资源仅移除资源列表记录，不级联清理已保存文档；文档库初始化会清除所有本地正文修改，须确认。

### 新建资源的标签

新建表单通过 [TagInput](react-workbench-components.md#taginput2026-11-09) 收集可选标签。按 Enter 或点添加，把中英文逗号分隔的值去除首尾空白后逐项加入。重复标签按大小写不敏感去重，保留首次输入的顺序与写法。沿用已有的 8 项和每项 40 字符上限，超限保留本批草稿并显示原因。创建时一并校验未添加的草稿，保存成功后标签可在详情查看，并进入现有资源搜索。数据继续使用原有资源信封。

## 本地体验

在仓库根目录执行 `npm ci`（已安装时可跳过）与 `npm run dev`，访问 `http://127.0.0.1:4510`。从侧栏或移动底栏切换页面；资源库中的“外观与偏好示例”打开偏好页，其他资源打开对应示例文档。浏览器存储按来源隔离，开发服务与其他域名的修改不会自动同步。

11 月 4 日首轮只使用 Chrome 验证，当时没有宣称 Safari / Firefox、真机安全区、屏幕阅读器、浏览器整页缩放或真实产品采用通过。字体放大检查指将基础字体由 16px 增至 32px，不等同于浏览器整页缩放；移动触控和安全区样式已提供，真机仍待后续验证。

旧官网的四个锚点 `#overview`、`#foundations`、`#components` 和 `#platforms` 仍可进入对应页面。晋级前 Chrome 生产构建复验七页、三档宽度、两档基础字号与明暗，共 84 / 84。晋级后的 Safari / Firefox 定向结果见[单一入口补验](#单一入口补验2026-11-09)。

### 窄桌面窗口的信息密度复评

2026-11-05，所有者通过 514px 宽的桌面侧窗指出整页信息密度偏低，确认问题包括控件、字段排列与留白。布局断点只决定可用空间，触控尺寸改按输入方式判断：fine pointer 的窄窗保持桌面控件；coarse / none 保留主要控件至少 44px。紧凑档同步收敛页头、主题预览、设置行、资源列表、文档工具区、底部导航与组件用法间距，正文阅读偏好保持独立。

设置表单可用宽度达到 28rem 时，窄桌面窗口也使用左侧说明 / 右侧控件的行式布局；较窄窗口或文字放大后回到单列。触屏窄窗保留安全区；紧凑档底栏使用 52px 高、链接 50px（命中 ≥44px）触控，触屏与鼠标都生效；非紧凑密度保留 72px 高度。输入方式适配按 DR-16，宽度 / 高度同时以 computed style 核对。既有偏好继续保留，保存紧凑档后生效；本轮不新增共享 token / API。所有者已认可本轮信息密度与底部导航调整，具体测量和验证见本周记录；跨环境补验与正式基准登记继续按各自出口推进。
