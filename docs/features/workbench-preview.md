# E-02：Workbench 三代表页运行范例

主要归属：[E：展示、页面范例与产品采用](../planning/topics.md#examples)，协同 F-01 / F-02 与 [C-02 共享组件](react-workbench-components.md)。2026-11-04 按所有者明确要求在 RadishUI 本仓 `apps/docs` 实施；兄弟产品继续只读。

## 目标与输入输出

以[现代圆角候选](../design/patterns/modern-rounded-v1.md)作为实现起点，展示站直接消费共享 token、控件与图标，形成资源库、设置和文档三页。范例不接产品接口，没有真实登录、权限判断、云端保存或协作编辑。

应用使用 hash 地址 `#/resources`、`#/settings`、`#/document`，资源文档为 `#/document/<id>`，章节地址继续附加 `/<section-id>`。应用导航属于展示站，不进入通用组件包，不增加产品路由依赖。

## 代表页与真实行为

| 页面 | 范例行为 | 明确边界 |
| --- | --- | --- |
| R1 资源库 | 初始 8 项合成资源；搜索、类型 / 状态筛选、详情、页大小 / 翻页 / 指定页、新建、确认删除、版本信息与资源打开 | 本地分页，只有当前版本；只读资源不可编辑或删除，未实现远端版本历史 / DataGrid |
| R2 外观与偏好 | 浅色 / 深色 / 跟随系统、中文 / English 控件文案、桌面主要控件高度、阅读字号 / 行距、目录、辅助说明与操作通知；保存与恢复默认 | 密度对应主要按钮 / 输入 / 选择控件的 36 / 40 / 44px 最小高度，不改变表格行高或全部容器间距；系统字体栈，内容语言保留；默认值保存后生效 |
| R3 文档 | 真实文字排版、按实际二 / 三级标题生成目录、章节定位、滚动当前项、纯文本编辑 / 保存、空文档、只读与复制链接 | 支持 ## / ### 标题和 > 提示，其余纯文本，非完整 Markdown / 富文本；链接不传递本机保存的正文 |

桌面侧栏独立底板、连续入口、当前项高亮；账号 / 工作区保留独立菜单。移动底栏保持整体胶囊、等分槽位与统一内收。文档正文占满除辅助栏与固定栏间隔之外的可用宽度，不再用固定行宽居中制造左右空白。

## 本地数据、失败与恢复

- 偏好、资源、文档使用三个 `radishui.*.v1` localStorage 键，包裹 `{ version: 1, data }`；读取时验证结构、枚举、长度、日期与资源 ID 唯一性。只有实际写入成功后更新已保存状态，不添加模拟成功延时。
- 缺少记录时使用合成初值，空数组是有效的空资源库。JSON 损坏、未知格式或浏览器存储不可用会显示真实失败，不用默认成功掩盖；恢复演示资源与重新初始化文档分别确认范围，不影响另外两类数据。
- 写入失败保留草稿；未保存离开有确认，刷新 / 关闭窗口使用浏览器离开提示。收到其他标签页的数据变更后提示重新载入并阻止覆盖，不承诺自动冲突合并。
- 复制链接只在 Clipboard API 成功后显示已复制；不可用时保留链接并提示手动复制。页面不执行站外消息发送。
- 文本经 React 正常转义，不解析任意 HTML；新建 / 编辑有长度和必填约束。示例账号、时间与资源均为合成内容，不引入真实个人数据。
- 资源上限 500 项，已保存文档修改上限 500 份；名称 / 标题最长 120 字符、资源摘要最长 1000 字符、正文最长 50000 字符。删除资源仅移除资源列表记录，不级联清理已保存文档；文档库初始化会清除所有本地正文修改，须确认。

## 本地体验

在仓库根目录执行 `npm ci`（已安装时可跳过）与 `npm run dev`，访问 `http://127.0.0.1:4510`。从侧栏或移动底栏切换页面；资源库中的“设置页面示例”打开偏好页，其他资源打开对应示例文档。浏览器存储按来源隔离，开发服务与其他域名的修改不会自动同步。

本轮只使用 Chrome 验证，没有宣称 Safari / Firefox、真机安全区、屏幕阅读器、浏览器整页缩放或真实产品采用通过。字体放大检查指将基础字体由 16px 增至 32px，不等同于浏览器整页缩放；移动触控和安全区样式已提供，真机仍待后续验证。
