# E-02：Workbench 三代表页运行范例

主要归属：[E：展示、页面范例与产品采用](../planning/topics.md#examples)，协同 F-01 / F-02 与 [C-02 共享组件](react-workbench-components.md)。2026-11-04 按所有者明确要求在 RadishUI 本仓 `apps/docs` 实施；兄弟产品继续只读。

## 目标与输入输出

以[现代圆角候选](../design/patterns/modern-rounded-v1.md)作为实现起点，展示站直接消费共享 token、控件与图标，形成资源库、设置和文档三页。范例不接产品接口，没有真实登录、权限判断、云端保存或协作编辑。

应用使用 hash 地址 `#/resources`、`#/settings`、`#/document`，资源文档为 `#/document/<id>`，章节地址继续附加 `/<section-id>`。应用导航属于展示站，不进入通用组件包，不增加产品路由依赖。

## 代表页与真实行为

| 页面 | 范例行为 | 明确边界 |
| --- | --- | --- |
| R1 资源库 | 初始 8 项合成资源；搜索、类型 / 状态筛选、详情、页大小 / 多页时的翻页与指定页、新建、确认删除、版本信息与资源打开 | 本地分页，只有当前版本；只读资源不可编辑或删除，未实现远端版本历史 / DataGrid |
| R2 外观与偏好 | 浅色 / 深色 / 跟随系统、中文 / English 控件文案、桌面控件与工作区密度、阅读字号 / 行距、目录、辅助说明与操作通知；保存与恢复默认 | 密度对应主要按钮 / 输入 / 选择控件的 36 / 40 / 44px 最小高度；紧凑档同时收紧桌面页头、设置行、资源列表、导航与用例间距，阅读正文字号 / 行距独立；系统字体栈，内容语言保留；默认值保存后生效 |
| R3 文档 | 真实文字排版、按实际二 / 三级标题生成目录、章节定位、滚动当前项、纯文本编辑 / 保存、空文档、只读与复制链接 | 支持 ## / ### 标题和 > 提示，其余纯文本，非完整 Markdown / 富文本；链接不传递本机保存的正文 |

桌面侧栏独立底板、连续入口、当前项高亮；账号 / 工作区保留独立菜单。移动底栏统一图标在上、文字在下，保持整体胶囊与统一内收，整体居中，按图标、标签与必要留白确定宽度；空间不足时在视口边距内收缩，触屏入口至少 44px。文档正文占满除辅助栏与固定栏间隔之外的可用宽度，不再用固定行宽居中制造左右空白。

## 本地数据、失败与恢复

- 偏好、资源、文档使用三个 `radishui.*.v1` localStorage 键，包裹 `{ version: 1, data }`；读取时验证结构、枚举、长度、日期与资源 ID 唯一性。只有实际写入成功后更新已保存状态，不添加模拟成功延时。
- 缺少记录时使用合成初值，空数组是有效的空资源库。JSON 损坏、未知格式或浏览器存储不可用会显示真实失败，不用默认成功掩盖；恢复演示资源与重新初始化文档分别确认范围，不影响另外两类数据。
- 写入失败保留草稿；未保存离开有确认，刷新 / 关闭窗口使用浏览器离开提示。收到其他标签页的数据变更后提示重新载入并阻止覆盖，不承诺自动冲突合并。
- 复制链接只在 Clipboard API 成功后显示已复制；不可用时保留链接并提示手动复制。页面不执行站外消息发送。
- 文本经 React 正常转义，不解析任意 HTML；新建 / 编辑有长度和必填约束。示例账号、时间与资源均为合成内容，不引入真实个人数据。
- 资源上限 500 项，已保存文档修改上限 500 份；名称 / 标题最长 120 字符、资源摘要最长 1000 字符、正文最长 50000 字符。删除资源仅移除资源列表记录，不级联清理已保存文档；文档库初始化会清除所有本地正文修改，须确认。

## 本地体验

在仓库根目录执行 `npm ci`（已安装时可跳过）与 `npm run dev`，访问 `http://127.0.0.1:4510`。从侧栏或移动底栏切换页面；资源库中的“设置页面示例”打开偏好页，其他资源打开对应示例文档。浏览器存储按来源隔离，开发服务与其他域名的修改不会自动同步。

11 月 4 日首轮只使用 Chrome 验证，当时没有宣称 Safari / Firefox、真机安全区、屏幕阅读器、浏览器整页缩放或真实产品采用通过。字体放大检查指将基础字体由 16px 增至 32px，不等同于浏览器整页缩放；移动触控和安全区样式已提供，真机仍待后续验证。

2026-11-05 继续复核三代表页，按所有者反馈将新用户 / 恢复默认的密度设为 compact，设置页桌面选择器列宽由 228px 收至 192px；已存偏好仍按原值读取。密度说明明确只调整主要桌面控件高度。移动内容区补充底栏对应的 scroll-padding-bottom，使程序滚动 / 聚焦时能避让底栏。组件用法独立入口归 [C-02.4](react-workbench-components.md)，不新增第四个产品代表页。Safari / Firefox 的补验是限定路径抽查，不替代完整环境矩阵。

### 窄桌面窗口的信息密度复评

2026-11-05，所有者通过 514px 宽的桌面侧窗指出整页信息密度偏低，确认问题包括控件、字段排列与留白。布局断点只决定可用空间，触控尺寸改按输入方式判断：fine pointer 的窄窗保持桌面控件；coarse / none 保留主要控件至少 44px。紧凑档同步收敛页头、主题预览、设置行、资源列表、文档工具区、底部导航与组件用法间距，正文阅读偏好保持独立。

设置表单可用宽度达到 28rem 时，窄桌面窗口也使用左侧说明 / 右侧控件的行式布局；较窄窗口或文字放大后回到单列。触屏窄窗保留纵向图文胶囊和安全区。既有偏好继续保留，保存紧凑档后生效；本轮不新增共享 token / API。所有者已认可本轮信息密度与底部导航调整，具体测量和验证见本周记录；跨环境补验与正式基准登记继续按各自出口推进。

### 2026-11-05 A 档去装饰与分页渐进披露

按所有者对“去除 AI 味”方案的确认，先实施不改共享 token / 组件语义 / 整体外壳的 A 档：

- R1 资源行去掉 36px 图标底、常驻浅底打开按钮与“已就绪”彩色胶囊；类型图标改为 16px 单色。状态色集中到 6px 圆点：已就绪使用成功色 + 柔色光晕，草稿使用警告色 + 柔色光晕，只读保留锁图标；文字仍以次级信息呈现，不恢复彩色胶囊。行悬停有底色，打开按钮仍保留 32px 命中区、悬停承托和键盘焦点。
- 分页改为渐进披露：单页只显示总数、每页条数与 `1 / 1`，隐藏翻页、页码和跳页；多页时才展开完整控件，无结果时只保留空态。每页条数选择器保留，作为进入多页演示的入口，避免 E-02.2 的真实多页路径被隐藏。
- 去掉 `.resource-table-spacer`，列表卡片结束于分页；详情面板改为白底 + 左侧细线，打开动作上移，移除 `margin-top: auto` 的底部双按钮。移动端详情改为底部弹层：≤799px 全宽贴底、顶部 20px 圆角、最大高度 86dvh、背板 / 关闭 / Escape 关闭，并保留安全区底部留白；800–1099px 仍用右侧抽屉。弹层标题直接使用资源名，状态与打开 / 更多动作合并为一行，去掉通用“资源详情”标题、内部重复标题和“当前资源”标签。
- 类型 tabs 去掉计数，避免“全部 8 / 文档 4 / 清单 2”不闭合的误导；规范 / 范例仍通过“全部”浏览，完整类型筛选不在 A 档扩展。
- 文档提示块用 `Info` 替代 `Sparkles`；设置页主题预览改成使用真实主题变量的小界面缩略图，无改动时显示“所有更改已保存”。

这是运行版清理，不是正式视觉基准登记；外壳浮框、字阶、全域状态色与共享 `ghost` 语义仍留到 B 档。验证事实、脚本和未覆盖面见[本周记录](../devlogs/2026-W45.md)。
